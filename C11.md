## C11 — Staging & Exfiltration

`sancadmin` staged harvested credential material into an archive on `GF-WS01` for later exfiltration, following the credential-access activity in C07.

| Category | Details |
| :---: | :---: |
| **Attack Method** | Local staging of harvested KeePass vault data into `keepass.zip` ahead of exfiltration |
| **Impact** | Consolidates credential-harvesting output (C07) into a single archive, reducing the number of exfil transfers and easing detection evasion |
| **MITRE ATT&CK** | **T1560** (Archive Collected Data) · **T1074** (Data Staged) |

### Key Evidence & Telemetry Logs

| Timestamp | Source Log | Event Details |
| :---: | :---: | :--- |
| **~12:10 PM** (post `tasklist \| findstr lsass`, C07) | `LAW-SilentCorridor (WindowsFile_CL)` | `keepass.zip` created on `GF-WS01` by `sancadmin` |

**Reasoning:** The archive appears immediately after the credential-enumeration sequence documented in C07 (cmdkey, KeePass, svc_backup targeting, LSASS prep), consistent with an actor consolidating harvested material before moving it off-host.

### Cross-SIEM Validation: LAW-SilentCorridor vs Defender XDR

| Source | Found? | What It Shows |
|---|---|---|
| **LAW-SilentCorridor** | Found | File creation event for `keepass.zip` on GF-WS01 |
| **Defender XDR** | Not found | No corresponding file-creation alert surfaced for this archive |
| **LAW-Cyber-Range** | Not found | No DNS or network egress logged for this host in-window — exfil channel unconfirmed |

**Key Finding:** Staging is confirmed via file telemetry, but the actual exfiltration transport (DNS tunneling, HTTPS, cloud storage, etc.) is **not evidenced** in the available telemetry — see investigation-gaps.md.

### Detection Recommendations

| Gap | Recommendation |
|---|---|
| Archive creation from a sensitive-sounding filename (`keepass.zip`) not flagged | Alert on archive/compression utility execution immediately following credential-access indicators (cmdkey, KeePass, LSASS enumeration) |
| No confirmed egress channel | Enable DNS and proxy/network logging in scope for future investigations to close this visibility gap |
| Defender XDR missed the file-creation event | Validate MDE file-monitoring coverage on GF-WS01; confirm sensor health |
